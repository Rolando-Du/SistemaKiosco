# Security Policy

## Reportar una vulnerabilidad

No publiques credenciales, datos personales ni información sensible en issues públicos.

Para reportar un problema de seguridad, utilizá el correo de contacto disponible en el perfil de GitHub del autor. Incluí descripción, pasos de reproducción, impacto estimado y versión o commit afectado.

## Reglas del proyecto

- No publicar contraseñas demo reutilizables.
- No versionar secretos o archivos con información sensible.
- Revisar bases SQLite y backups antes de compartirlos.
- Mantener FastAPI, SQLAlchemy, React y dependencias actualizadas.
- Ejecutar las validaciones de CI antes de integrar cambios.

## Datos

No incluir información real de ventas, clientes, proveedores o usuarios en ejemplos públicos, screenshots o backups versionados.
